## Getting Started

Follow the instructions below to run the project locally.

## Prerequisites

Make sure you have the following installed:

- **Node.js**

  Install Node.js from:

  ```sh
  https://nodejs.org/en/
  ```

  ⚠️ **Supported Node.js version:** `16.x`

- **npm** (comes with Node.js)

  Update npm to the latest version:

  ```sh
  npm install -g npm@latest
  ```

## Installation

1. **Clone the repository**

2. **Navigate to the project directory**

3. **Install dependencies**

```sh
npm install
```

If dependency issues occur, you may use:

```sh
npm install --force
```

⚠️ Use `--force` only if necessary, as it may install incompatible versions.

Before running the server, configure the environment settings.

- Edit the app.json file and Add or Update the following variables mentioned in that file

## app.json
Make sure your ETH RPC node is reachable.

### To start the server

```sh
npm start
```

Now you server will be up and running.
